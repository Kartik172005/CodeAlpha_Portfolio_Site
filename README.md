# CodeAlpha_Portfolio_Site

A clean, modern, and high-performance personal portfolio website built using semantic HTML5 and styled with advanced CSS layout strategies as part of the Frontend Development Internship at CodeAlpha.

## 🚀 Features

- **Professional Sections:** Dedicated layout segments including About Me, Projects Showcase, Skills Inventory, and Contact information.
- **Responsive Architecture:** Fully optimized to preserve structural integrity on devices of all screen widths.
- **Smooth Navigation & Scroll:** Enhances user experiences with fluid scroll behaviors across section links.
- **Visual Enhancements:** Packed with CSS transitions, button hover interactions, and clean typography layouts.

## 🛠️ Built With

* **HTML5:** Highly semantic and organized document outline matching standard professional portfolio profiles.
* **CSS3:** Advanced flex/grid controls, custom layout scaling, typography tracking, and smooth transitions.
